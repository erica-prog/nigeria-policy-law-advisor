# Law & Policy Advisor

A research aid for practising lawyers: upload the documents of a matter, ask
questions, and get answers whose every claim cites a passage the lawyer can
open. Grounded in the matter's own documents first, official sources second,
and never in the model's memory.

- Run it: [docs/17-web-app-mvp.md](docs/17-web-app-mvp.md) (FastAPI + the
  browser client in `web/`; `uv run uvicorn policy_advisor.api.main:app --reload`).
- How it works and why: start at [docs/00-overview.md](docs/00-overview.md).
- Working in this repository: `AGENTS.md`.
- Where it is going: [docs/19-adr-001-multi-jurisdiction-legal-platform.md](docs/19-adr-001-multi-jurisdiction-legal-platform.md).
