    Activate the advisor

    1. Create an Anthropic account at console.anthropic.com.
    2. Add a payment method under Billing. You pay Anthropic directly for what Claude reads and writes for you, typically a few cents per question. The person running this app never pays for your usage and never sees it.
    3. Create an API key under API Keys and copy it. It starts with sk-ant-.
    4. Paste it below and press Save and activate.

    Your key is stored encrypted on this server, used only for your own questions, and never shown again. You can remove it any time from Your cases.
